# Privacy Policy - University Course Management System (UCMS)

Last updated: 2026-11-26

UCMS is a personal tool used only by its owner to organize the owner's own lecture materials and lecture videos and to keep them in the owner's own Google Drive.

## Data we access

The app accesses files in the owner's own Google Drive using the Google Drive API: it saves lecture videos, subtitles and its own settings, and reads files in the same Drive that the owner's other personal tools have created.

## How data is used

Data is used only for the owner's own study. It is not shared with, sold to, or disclosed to any third party. It is not used for advertising.

## Storage

Files and credentials are stored only on the owner's own devices and in the owner's own Google Drive. The developer does not operate any server that collects or stores user data.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions
